## Files and build targets

| Board            | Top-level source                                   | Arch    | Single `make` target           | Built when            |
| ---------------- | -------------------------------------------------- | ------- | ------------------------------ | --------------------- |
| Raspberry Pi 4   | `arch/arm64/boot/dts/broadcom/bcm2711-rpi-4-b.dts` | `arm64` | `broadcom/bcm2711-rpi-4-b.dtb` | `CONFIG_ARCH_BCM2835` |
| BeagleBone Black | `arch/arm/boot/dts/ti/omap/am335x-boneblack.dts`   | `arm`   | `ti/omap/am335x-boneblack.dtb` | `CONFIG_SOC_AM33XX`   |
| STM32MP157 DK2   | `arch/arm/boot/dts/st/stm32mp157c-dk2.dts`         | `arm`   | `st/stm32mp157c-dk2.dtb`       | `CONFIG_ARCH_STM32`   |

The top-level `Makefile` turns a goal such as `broadcom/bcm2711-rpi-4-b.dtb` into a build of that file under `arch/$(SRCARCH)/boot/dts/`. The `dtbs` target builds every dtb whose `dtb-$(CONFIG_...)` line is enabled in the directory's `Makefile`; the last column names that symbol.[^make]

The Raspberry Pi 4 file under `arch/arm64` is a one-line wrapper. It includes `arm/broadcom/bcm2711-rpi-4-b.dts`, which the build finds through `scripts/dtc/include-prefixes/arm`, a link to `arch/arm/boot/dts`.[^rpi]

## Root node, console and memory

| Board            | Root `compatible`                                       | Root `model`                                           |
| ---------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| Raspberry Pi 4   | `"raspberrypi,4-model-b", "brcm,bcm2711"`               | `"Raspberry Pi 4 Model B"`                             |
| BeagleBone Black | `"ti,am335x-bone-black", "ti,am335x-bone", "ti,am33xx"` | `"TI AM335x BeagleBone Black"`                         |
| STM32MP157 DK2   | `"st,stm32mp157c-dk2", "st,stm32mp157"`                 | `"STMicroelectronics STM32MP157C-DK2 Discovery Board"` |

| Board            | `/chosen/stdout-path`                                  | Alias it uses      | `/memory` node in the source                                                  |
| ---------------- | ------------------------------------------------------ | ------------------ | ----------------------------------------------------------------------------- |
| Raspberry Pi 4   | `"serial1:115200n8"`, set in `bcm2711-rpi-4-b.dts`     | `serial1 = &uart1` | `memory@0`, `reg = <0 0 0>`, commented as filled in by the bootloader         |
| BeagleBone Black | `"serial0:115200n8"`, set in `am335x-bone-common.dtsi` | `serial0 = &uart0` | `memory@80000000`, `reg = <0x80000000 0x20000000>`                            |
| STM32MP157 DK2   | `"serial0:115200n8"`, set in `stm32mp157c-dk2.dts`     | `serial0 = &uart4` | `memory@c0000000`, `reg = <0xc0000000 0x20000000>`, in `stm32mp15xx-dkx.dtsi` |

The aliases are set in `bcm283x.dtsi`, `am33xx.dtsi` and `stm32mp15xx-dkx.dtsi`. Two entries show the override rule at work:

- `bcm283x.dtsi` sets `stdout-path = "serial0:115200n8"`. The Raspberry Pi 4 file sets it again to `serial1`, with a comment that the board uses the 8250 auxiliary UART instead of the PL011.
- `am335x-bone-common.dtsi` describes 256 MB at `0x8000_0000`. `am335x-boneblack-common.dtsi`, included later, redefines the same node with 512 MB.

## Top-level files

The Raspberry Pi 4 board file. Its license tag is `GPL-2.0`; it has no copyright line.

<CodeBlock path="arch/arm/boot/dts/broadcom/bcm2711-rpi-4-b.dts" project="Linux v6.18.55" lang="dts" simplified>

```dts
/dts-v1/;
#include "bcm2711.dtsi"
#include "bcm2711-rpi.dtsi"
#include "bcm283x-rpi-led-deprecated.dtsi"
#include "bcm283x-rpi-usb-peripheral.dtsi"
#include "bcm283x-rpi-wifi-bt.dtsi"
#include <dt-bindings/leds/common.h>

/ {
	compatible = "raspberrypi,4-model-b", "brcm,bcm2711";
	model = "Raspberry Pi 4 Model B";

	chosen {
		/* 8250 auxiliary UART instead of pl011 */
		stdout-path = "serial1:115200n8";
	};
	/* ... */
};
```

</CodeBlock>

## Related variants in the same folders

- `arch/arm64/boot/dts/broadcom/`: `bcm2711-rpi-400.dts` and `bcm2711-rpi-cm4-io.dts` cover the Raspberry Pi 400 and the Compute Module 4 IO board.
- `arch/arm/boot/dts/ti/omap/`: `am335x-boneblack-wireless.dts` covers the BeagleBone Black Wireless.
- `arch/arm/boot/dts/st/`: `stm32mp157c-dk2-scmi.dts` includes `stm32mp157c-dk2.dts` and `stm32mp15-scmi.dtsi`, with the root compatible `"st,stm32mp157c-dk2-scmi", "st,stm32mp157"`.

[^make]: Top-level `Makefile` at Linux v6.18.55: `dtstree := arch/$(SRCARCH)/boot/dts`, the `%.dtb` rule and the `dtbs` target. The `dtb-$(CONFIG_...)` lines are in `arch/arm64/boot/dts/broadcom/Makefile`, `arch/arm/boot/dts/ti/omap/Makefile` and `arch/arm/boot/dts/st/Makefile`.

[^rpi]: `arch/arm64/boot/dts/broadcom/bcm2711-rpi-4-b.dts`, `scripts/dtc/include-prefixes/arm` and the files in `arch/arm/boot/dts/broadcom/` at Linux v6.18.55.

[^bbb]: `arch/arm/boot/dts/ti/omap/` and `arch/arm/boot/dts/tps65217.dtsi` at Linux v6.18.55.

[^st]: `arch/arm/boot/dts/st/` at Linux v6.18.55.
