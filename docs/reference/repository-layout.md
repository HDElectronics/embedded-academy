# Repository layout

The repository is a pnpm workspace. Put new files where this layout says. A new top-level folder needs an ADR.

## Top-level folders

| Path                      | Contents                                                                  |
| ------------------------- | ------------------------------------------------------------------------- |
| `apps/site/`              | Astro site: routes, layouts, search                                       |
| `content/courses/<slug>/` | MDX lessons, one folder per module (`00-orientation` ...)                 |
| `packages/boards/`        | Board data and Zod schemas: `rpi4`, `bbb`, `stm32mp157`                   |
| `packages/anim/`          | Animation components (`BootChain`, `MemoryMap`, `PrivilegeLadder` ...)    |
| `packages/ui/`            | Design system: tokens, fonts, base components                             |
| `labs/`                   | Lab container, QEMU scripts, lab sources                                  |
| `logs/`                   | Real serial captures used by lessons                                      |
| `docs/`                   | These Sphinx docs: `tutorials/`, `how-to/`, `reference/`, `explanation/`  |
| `scripts/github/`         | Scripts that set up GitHub, such as the project setup script              |
| `e2e/`                    | Playwright end-to-end and accessibility tests, run against the built site |
| `.github/`                | Workflows, issue forms, PR template, CODEOWNERS                           |
| `LICENSES/`               | License texts for REUSE                                                   |

## The docs folder

| Path                          | Contents                                  |
| ----------------------------- | ----------------------------------------- |
| `docs/conf.py`                | Sphinx configuration                      |
| `docs/requirements.in`        | Top-level docs dependencies               |
| `docs/requirements.txt`       | Pinned docs dependencies, generated by uv |
| `docs/_static/`               | Theme overrides for the design system     |
| `docs/tutorials/`             | Guided first runs                         |
| `docs/how-to/`                | Task guides                               |
| `docs/reference/`             | Exact facts                               |
| `docs/explanation/`           | Background and reasoning                  |
| `docs/explanation/decisions/` | Architecture decision records (MADR)      |

## Root files

| File                | Purpose                                                |
| ------------------- | ------------------------------------------------------ |
| `README.md`         | What the project is and how to start                   |
| `AGENTS.md`         | Rules for AI coding agents and contributors            |
| `CLAUDE.md`         | Claude Code entry point; imports `AGENTS.md`           |
| `CONTRIBUTING.md`   | How to contribute, in short                            |
| `SECURITY.md`       | How to report a vulnerability                          |
| `.readthedocs.yaml` | Read the Docs build configuration                      |
| `CHANGELOG.md`      | Release notes, generated by release-please             |
| `REUSE.toml`        | License information for files that can't hold comments |
