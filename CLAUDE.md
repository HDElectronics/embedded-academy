# CLAUDE.md

All project rules live in AGENTS.md, shared with every coding agent. Follow it.

@AGENTS.md

## Claude Code specifics

- Use the `gh` CLI for issues, PRs and the GitHub Project (`gh issue`, `gh pr`, `gh project item-edit`). Project commands need the `project` token scope.
- Commit with `git commit -s` and end messages with the attribution trailer the session provides.
- Run the checks from AGENTS.md "Commands" before reporting a change as done, and report failures with their output.
